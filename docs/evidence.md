# Evidence format

Every protocol claim in `specs/` traces back to a hashed artifact in `evidence/`.

- `evidence/raw/*.har`: HTTP Archive captures recorded by `tools/capture/proxy.mjs` while the unmodified SDK ran `tools/capture/scenario.js` against the Firebase Emulator Suite. Streaming responses (WebChannel backchannel, WebSocket frames) are recorded incrementally.
- `evidence/raw/emulator-web-scenario.results.json`: outcomes of the browser scenario against the emulator.
- `evidence/rea/*.json.gz`: evidence bundles produced by REA (`rea-agents` 6.7.0). `har-*` come from normalised HARs (`tools/capture/normalize-har.mjs`); `js-*` are static analyses of the public npm SDK bundles, used to find endpoints and error mappings.
- `evidence/manifest.json`: SHA-256 and size of every artifact, generated by `node tools/evidence/build-manifest.mjs`.
- `evidence/summary.json`: REA evidence ids and record counts.

Verify locally:

```sh
cd evidence && node -e 'const c=require("node:crypto"),f=require("node:fs");for(const a of require("./manifest.json").artifacts){const h=c.createHash("sha256").update(f.readFileSync(a.path)).digest("hex");console.log(h===a.sha256?"ok  ":"BAD ",a.path)}'
```
